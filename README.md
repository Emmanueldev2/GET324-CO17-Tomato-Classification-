# GET 324 — Lab Exercise 10 (Mini-Project)
## Group CO17/EE17 — Healthy Tomato vs Tomato Early Blight

A binary image classification web app that identifies whether a tomato leaf is **healthy** or shows signs of **early blight**, using a MobileNetV2 transfer learning model deployed with Streamlit.

## Project Structure
```
├── app.py                     # Streamlit application
├── requirements.txt           # Python dependencies
├── notebooks/
│   └── train_model.ipynb      # Data prep, training, evaluation
├── model/
│   └── tomato_model.h5        # Trained model (generated by the notebook)
└── README.md
```

## Dataset
[PlantVillage dataset](https://www.kaggle.com/datasets/emmarex/plantdisease) (Kaggle) — `Tomato_healthy` and `Tomato_Early_blight` classes.

## How to Run Locally
```bash
git clone https://github.com/Emmanueldev2/GET324-CO17-Tomato-Classification-.git
cd GET324-CO17-Tomato-Classification-
pip install -r requirements.txt
streamlit run app.py
```

## How to Train the Model
1. Download the PlantVillage dataset from Kaggle (see `notebooks/train_model.ipynb` for instructions).
2. Open and run `notebooks/train_model.ipynb` top to bottom.
3. The trained model is saved to `model/tomato_model.h5`.

## Deployment
Deployed on Streamlit Community Cloud: `https://get324-co17-tomato-classification.streamlit.app/`
